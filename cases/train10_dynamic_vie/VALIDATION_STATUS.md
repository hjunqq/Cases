## 已测试并被否决的假设:自由面高程 bounfreez(结论:原值 `62*0.` 正确)

`1.pre` 的 62 个波动输入节点全部填 `freez=0`,而按说明书规则(每个节点取其向上
投影到地表的竖向坐标)与网格实际:x=386 一侧地表 y=0(填 0 正确),**x=0 一侧地表
y=110**。源码 `Fem.f90:13926` 用它算自由面反射延迟
`timer2=(freez-inpcord)/c+(freez-z)/c`,差 110 m 对应 S 波 0.162 s ≈ **8 个时间步**
的相位错位 —— 形状上正对"波形有时移"。

**但实测把 x=0 一侧改为 110 后,`dynamic_vie_rhs` 判 FAIL**:未声明的 y 向出现
7.462e+07 的基底力(两侧自由面不对称,反射不再抵消)。因此**未采纳**,不为迁就假设
去放宽判据。

**根因已澄清(用户 2026-09-09 指出:x=0 不能作为边界判定,要按地基的实际范围判)**:
我先前用"每个 x 列的最高节点"当地表,把**结构**也算了进去。按组核实:

| 组 | y 范围 |
|---|---|
| FarField(地基) | −250 ~ 0 |
| Dam | 0 ~ 110 |
| Foundation | 0 ~ 110 |

62 个波动输入节点**全部属于 FarField**,而地基在 x=0 与 x=386 两侧的顶面**都是
y=0**。那个 y=110 是**坝体**(Dam 组 x 覆盖 0~156),不是地基自由面。
所以原值 `62*0.` **是正确的**,x=0 也不是"边界穿过结构" —— 坝体本就坐在地基上。

两重独立确认:判据 FAIL + 用户按地基范围的判定。判据挡住了一次基于错误几何判读的
修改,这正是它该做的事。
