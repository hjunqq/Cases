## ✅ 实测:附加质量已生效(2026-09-09,用户指出根因后)

先前对照实验(只翻转 `Icaddmass`)结果**逐字节相同**,附加质量看不出效果。
用户指出根因:**地震输入采用振动法,即把地震加速度施加到有质量的建筑物上**。

据此查出 deck 的两处错误(与附加质量接线无关,是更根本的缺陷):

1. **`APPEAR_PROCESS` 第一行是 `1 0 0`** —— 只有 GROUP1(ρ=0 的**无质量地基**)参与
   运算,结构 GROUP2/3(ρ=2400)根本不出现。总质量为零 → 地震荷载 `−M·a` 恒为 0 →
   模型纹丝不动(位移 4.8e-08,且 0.1 s 与 5 s **一模一样**)。
   第二行 `1 1 1` 就写在文件里,但 `NBLKS=1` 让它永远读不到。
   **已改为 `1 1 1`**(备份 `1.glb.bak_appear_20260909`)。
2. **激励方向填在 y 槽** —— `1.man` 的 `earthquake_curve` 是 `0 2`,而曲线 2 在
   `1.loa` 里的注释自称 **"x-a"(x 向加速度)**。曲线是 x 的、方向却填了 y,正是
   PRJ-6057 那个形状。**已改为 `2 0`**(备份 `1.man.bak_eqdir_20260909`)。

改后对照实验(同一 deck,只翻转 Icaddmass):

| | 末块 \|Ux\| 峰 |
|---|---|
| `Icaddmass=1` | **5.936573e-04** |
| `Icaddmass=0` | 4.783875e-04 |

**+24%**,方向一致(湿面 x=0 的法向沿 x,附加质量加在 x,激励也在 x)。
对照:改方向之前是竖向激励,附加质量只在 x,相对差异仅 1e-5 —— 与几何完全吻合。

**附加质量的接线与生效,至此都有实测证据。**
